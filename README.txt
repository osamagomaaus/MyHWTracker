HOMEWORK TRACKER WEBSITE

Static public site for the Homework Tracker desktop application.

Files:
- index.html: homepage and app overview
- privacy.html: privacy policy and data practices
- terms.html: terms of service
- styles.css: shared responsive styling
- script.js: mobile navigation and current-year display

To publish on GitHub Pages:
1. Put these files at the root of the MyHWTracker GitHub repository.
2. Enable GitHub Pages in repository settings for the branch and folder containing these files.
3. Confirm the pages are public:
   https://ox0sama.github.io/MyHWTracker/index.html
   https://ox0sama.github.io/MyHWTracker/privacy.html
   https://ox0sama.github.io/MyHWTracker/terms.html
4. Enter those exact homepage, privacy policy, and terms links in Google Auth Platform > Branding.
5. Verify ox0sama.github.io and add it as an authorized domain in Google Cloud. Then request branding verification again.
